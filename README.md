# 💡 Idea Box（アイディアボックス）

タスクじゃない。**いつかやるかもしれない、馬鹿げた・想像的なアイディアを放り込んでおく箱。**

期限もToDoもなし。思いついた瞬間に放り込んで、たまに「✨ 発掘」して眺めてニヤニヤする。
[Kiroku](https://github.com/gyaruweijing-tech/kiroku)（真面目な進捗管理）と対になる遊び場アプリ。

## 起動

```bash
npm install
npm run dev
```

→ http://localhost:3001 （kiroku と同時起動できるよう 3001 番）

## 使い方

- 上の入力欄に一言書いて **＋ 放り込む**（Enter でもOK）
- カードをクリックして中身を育てる（本文は Markdown 対応・自動保存）
- **✨ 発掘する** … 過去のアイディアをランダムに1つ掘り起こす。埋もれた妄想との再会が目玉機能
- 整理は最小限：
  - **タグ** … 自由につける（`#AI` `#発明` など）。チップをクリックで絞り込み
  - **ワクワク度 ⚡1〜3** … 優先度じゃなくて「ときめき」
  - **育ち具合 🌱→🌿→🌳** … アイディアは完了しないので、ステータスではなく成長で表す
- **🗑 ゴミ箱** … 即削除しない（捨てたアイディアも後で惜しくなるので）
- **書き出し / 読み込み** … JSON でバックアップ・引っ越し

## 構成（kiroku と同じ形）

- `app/page.tsx` … 画面（UI）
- `lib/types.ts` … データの型（契約）
- `lib/storage.ts` … 保存ロジック（**ここを差し替えれば localStorage → API/DB にできる**）
- `lib/seed.ts` … 初期アイディア（見本を兼ねる）

データはブラウザの localStorage（キー: `ideabox.ideas.v1`）に保存されます。
